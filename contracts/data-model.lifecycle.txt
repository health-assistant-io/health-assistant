# Lifecycle inventory — health-assistant/core (constitution rule 10 / guidelines/data-model.md §7)
#
# Format: `table :: record|operational|transient`
# Gate D6 (scripts/check-data-model.sh) reads this file: every mapped table must
# be classified exactly once.
#
#  * record       — clinical/record data; retained with the subject (patient,
#                   user or tenant) and erased only when the subject is erased
#                   (tombstoned where the FHIR facade needs proof-of-existence)
#  * operational  — bounded retention; a `retention_policies` row names the
#                   cutoff and a named job enforces it
#  * transient    — prunable at will (caches, runtime sessions)
#
# The code-side mirror is `app/core/data_lifecycle.py`; both change together.

# --- identity + tenancy ---
tenants             :: record        tenant boundary; erased only by the tenant-erasure walker
users               :: record        accounts; erased with the user/tenant (self-service DELETE /users/me)
instance_settings   :: record        instance facts (auth_mode/demo_mode) consumed once at init
system_settings     :: record        operator-managed system configuration
system_integrations :: record        operator-managed system integration configuration
oauth_clients       :: record        SMART/OAuth client registrations; erased with the tenant
auth_sessions       :: transient     refresh families; prunable once absolutely expired

# --- data-lifecycle control plane ---
