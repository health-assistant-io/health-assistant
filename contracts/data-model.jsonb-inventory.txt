# JSONB inventory — health-assistant/core (constitution rule 6 / guidelines/data-model.md §5)
#
# Format: `table.column :: keep-open|typed-out   <reason>`
# Gate D5 (scripts/check-data-model.sh) reads this file: every JSON/JSONB
# model column must appear exactly once with a verdict, and every entry's
# table must exist. Adding a JSONB column = adding its row in the same commit.
#
# Reasoning record (the human-readable table lives in plan 2 §4):
#  * keep-open  — genuinely open payload: LLM content blocks, FHIR R4
#                 structures (spec-open Extension[]/CodeableConcept/...),
#                 extension-owned config, wire captures, layout documents,
#                 per-type metadata blueprints driven by a schema column.
#  * typed-out  — the app filters/joins/constrains it, or its shape is a
#                 contract that belongs in typed columns; a named plan
#                 rewrites it.
#
